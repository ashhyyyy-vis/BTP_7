# Setup and Usage Instructions

## Step 1: Setup WSL
If you're on Windows, install and setup Windows Subsystem for Linux (WSL):
- Open PowerShell as Administrator
- Run: wsl --install
- Restart your computer and complete the Ubuntu setup
- Set up your Ubuntu user and password

## Step 2: Navigate to Repository
Once WSL is running, navigate to the project directory:
```bash
cd /home/viseash/Ashley/BTP
```

## Step 3: Setup Python 3.12 with uv Virtual Environment
Install uv and create a Python 3.12 virtual environment:
```bash
# Install uv if not already installed
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create virtual environment with Python 3.12
uv venv --python 3.12

# Activate the virtual environment
source .venv/bin/activate

# Install dependencies
uv pip install datasets numpy scipy soundfile faster-whisper python-dotenv
```

## Step 4: Install ffmpeg with AMR-NB Encoder
```bash
# Install ffmpeg with AMR-NB support
sudo apt-get update
sudo apt-get install ffmpeg libopencore-amrnb

# Verify AMR-NB encoder is available
ffmpeg -encoders | grep -i amr
```

## Step 5: Authenticate with Hugging Face
```bash
# Login to Hugging Face (requires account and access token)
huggingface-cli login

# Or create .env file with HF_TOKEN
echo "HF_TOKEN=your_token_here" > .env
```

## Step 6: Extract Audio Data
Extract Hindi speech from IndicVoices dataset:
```bash
python -m scripts.extraction --out data --max-hours 3 --hf-token <YOUR_HF_TOKEN>
```

This will:
- Download and extract clean Hindi speech
- Create 16 kHz WAV files in data/clean/
- Generate data/manifest.csv with metadata

## Step 7: Degrade Audio
Simulate telephone channel degradation for synthetic, MUSAN, or DEMAND:
```bash
# Synthetic
python -m scripts.degrade --data data --noise-type synthetic

# MUSAN
python -m scripts.degrade --data data --noise-type musan --noise-dir data/noise/musan

# DEMAND
python -m scripts.degrade --data data --noise-type demand --noise-dir data/noise/demand --noise-group-by dir
```

This will:
- Check data/clean8k/ and create 8 kHz clean audio if not present
- Apply AMR-NB codec and noise mixing
- Save files to data/degraded/<noise_type>/
- Write metadata to data/degraded/<noise_type>/manifest_degraded.csv

## Step 8: Evaluate ASR
Evaluate Whisper ASR model on degraded audio:
```bash
# Local model
python -m scripts.eval_asr --data data --noise-type musan --model small

# Cloud Groq model
python -m scripts.eval_asr --data data --noise-type musan --backend groq --model whisper-large-v3 --groq-key <YOUR_GROQ_KEY>
```

Results are saved to:
- `artifacts/Metrics/<noise_type>/ASR/asr_<model>.jsonl`
- `artifacts/Metrics/<noise_type>/ASR/asr_summary_<model>.csv`

### Sharded ASR Evaluation (Multiple Machines)
On each machine:
```bash
python -m scripts.eval_asr --data data --noise-type musan --num-shards 3 --shard-id 0
python -m scripts.eval_asr --data data --noise-type musan --num-shards 3 --shard-id 1
python -m scripts.eval_asr --data data --noise-type musan --num-shards 3 --shard-id 2
```
Shards are written to `artifacts/shards/`. Merge all shards with:
```bash
python -m scripts.eval_asr --data data --noise-type musan --merge
```

## Step 9: Denoise / Speech Enhancement
Run front-end enhancers over degraded 8 kHz audio:
```bash
python -m scripts.denoise --data data --noise-type musan --methods wiener_dd dfn
```
Output:
- Enhanced audio in `artifacts/Metrics/<noise_type>/Enhancement/<method>/`

## Step 10: Compute Enhancement Metrics
Calculate SI-SDR, STOI, and PESQ:
```bash
python -m scripts.enh_metrics --data data --noise-type musan --front-ends wiener_dd dfn
```
Output:
- `artifacts/Metrics/<noise_type>/Enhancement/enh_metrics_summary.csv`
- `artifacts/Metrics/<noise_type>/Enhancement/enh_metrics_per_file.csv`

## Step 11: Evaluate Post-Enhancement ASR
Compare enhanced speech against original degraded speech on ASR:
```bash
python -m scripts.eval_enh --data data --noise-type musan --model small --front-ends wiener_dd dfn
```
Output:
- `artifacts/Metrics/<noise_type>/ASR/enh_summary_<model>.csv`
